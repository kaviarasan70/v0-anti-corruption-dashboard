## Sample Reports (Database)

When you seed the database with `scripts/002_seed_sample_reports.sql`, you get **15 realistic citizen submissions** with the following status distribution:

### Status Breakdown
- **Pending** (7 reports): Issues reported but not yet addressed
- **In Progress** (5 reports): Active repair/resolution work started
- **Resolved** (3 reports): Successfully completed

### Categories Covered
- Potholes & Road Damage (4 reports)
- Water Issues (4 reports)
- Street Lights (3 reports)
- Drainage (1 report)
- Power Outages (1 report)
- Traffic Signals (1 report)
- Garbage (1 report)

### Report Features
Each sample report includes:
- Unique ID (UUID)
- Category and location
- Detailed description
- Current status
- Created date (realistic timestamps)
- Last updated date (shows workflow progression)

## How to Modify Data

### Add More Projects
Edit `app/actions/fetch-projects.ts` and add to the returned array.

### Add More Grievances
Edit `components/grievance-map.tsx` and add to the `grievances` array.

### Seed More Sample Reports
Edit `scripts/002_seed_sample_reports.sql` and add more INSERT statements.

### Connect Real Data Sources
- **Google Sheets**: Enable Google Sheets integration in `lib/google-sheets-integration.ts`
- **Supabase Database**: All reports submitted through the form are automatically stored
- **API Integration**: Replace fetch functions with your government data API
